# Project Overview - Yanolja Clone Flutter App

## Core Identity
You are working on a **mobile-only Flutter application** that clones the Yanolja (야놀자) accommodation booking platform. This project is strictly focused on **Android and iOS platforms only**.

## Critical Platform Restrictions
🚫 **NEVER suggest or implement:**
- Web platform features or builds
- Linux platform support
- Windows platform support  
- macOS platform support
- Any desktop-specific UI patterns

✅ **ALWAYS focus on:**
- Mobile-first design principles
- iOS and Android platform specifications
- Touch-friendly UI interactions
- Mobile performance optimization

## Project Characteristics
- **Language Context**: Korean UI conventions and comments
- **Target Users**: Korean accommodation booking service users
- **Architecture**: Clean Architecture with Riverpod state management
- **Authentication**: Firebase Auth with Google Sign-In
- **Maps**: Google Maps integration for location features
- **Data**: Mock data for development (no backend dependency)

## Key Business Domains
1. **Accommodation Types**: 호텔 (Hotels), 펜션 (Pensions), 리조트 (Resorts), 한옥 (Traditional Korean Houses)
2. **User Features**: Search, Booking, Saved Items, User Profiles
3. **Navigation**: Bottom tab navigation with 6 main sections

Remember: This is a **mobile-only project** - any suggestions should align with mobile app development best practices.
