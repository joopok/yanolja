# Yanolja Clone App

야놀자 앱의 클론 프로젝트입니다. Flutter를 사용하여 개발되었으며, **Android와 iOS 플랫폼**을 지원합니다.

## 지원 플랫폼
- ✅ Android
- ✅ iOS
- ❌ Web (지원하지 않음)
- ❌ Linux (지원하지 않음)
- ❌ Windows (지원하지 않음)
- ❌ macOS (지원하지 않음)

## 주요 기능
- 숙소 검색 및 예약
- 카테고리별 숙소 분류 (호텔, 펜션, 리조트, 한옥)
- 사용자 인증 (Firebase Auth)
- 찜하기 기능
- 예약 내역 관리

## 아키텍처
- Clean Architecture
- Riverpod (상태 관리)
- GoRouter (내비게이션)
- Firebase (인증)
